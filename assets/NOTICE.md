# 角色素材来源

本项目使用 [dsh-whale-galgame](https://github.com/JAdpp/dsh-whale-galgame/blob/main/assets/default/pet-dafeiyu.webp) 的 Q 版图集，保留其 [角色素材授权与署名](https://github.com/JAdpp/dsh-whale-galgame/blob/main/THIRD_PARTY_LICENSES.md)。角色形象源自上善，ZipZipPipe 提供鲸鱼娘女仆设计，JAdpp 项目重绘图集时参考了 [f0909172434 的桌宠](https://github.com/f0909172434/dsh-deepseek-girl-pet)。

`whale.png` 从原图集选取第 0、1、6、7、21、5、23、8、32、9、3 帧（从 0 开始），取头部和上半身，等比缩小并排列成贴图条。`WhaleMate/Portraits.h` 是同一素材的 RGB565 转换版本。角色素材沿用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。
